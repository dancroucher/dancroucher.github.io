Bugs & correctness

high

Event-listener imbalance: 64 add vs 32 remove

Many are fine (static window listeners on the main module), but several handlers in Inactivity, Search, player.js, and the YouTube iframe shim fire during view transitions when their work is wasted. Audit each addEventListener that lacks a matching teardown and gate them behind the view state that needs them.

med

tape-share file store is racy, Vercel-hostile

api/utils/share-store.js falls back to a JSON file read/written synchronously on every request with no locking. Two concurrent POST /api/tape-share calls can corrupt each other. On Vercel (read-only FS) it silently no-ops unless Upstash is configured. Add a startup warning when Redis env vars are absent.

med

Dynamic import() per request in server.js

Every API route does await import('./api/...') inside the handler. Module cache means subsequent requests are fast, but the first hit on each route pays the import cost and error stacks are harder to trace. Import once at boot instead.

med

innerHTML for the // < title swap

The logo typewriter now lives in useLogoTypewriter.ts. It still uses innerHTML to write the back-arrow — safe because the string is a constant, but a one-copy-paste XSS vulnerability if a tape title ever gets interpolated. Replace with textContent + a styled element.

med

Stale console.log in shipped bundles

TapesTable3D.tsx:900 logs on WebGL context restore. demo.js:189 logs when polling infinite tape state. Bundles are minified so the noise is reduced, but stripping all console.* calls via esbuild's drop: ['console'] is the clean fix.

Performance

high

Recorder GLB: compress + remove dead texture folder

cassetterecorder.glb is 1.7 MB on disk. Run it through gltf-transform (Draco + KTX2 textures) — expect 80–90% size drop with no visible quality loss. Once optimised, delete the 94 MB unity/ texture folder (tracked in git, never loaded at runtime) and recorder.fbx (240 kB, also unused).

med

Background MP4s: 264 MB served as raw files

140 MB video/ + 45 MB anime/ + 79 MB vintage/. Re-encode at lower bitrate, serve via CDN with Cache-Control: immutable, add preload="none" so only the active video is fetched.

med

Strip console.* in production build

build-tapes.js has process.env.NODE_ENV defined but not drop: ['console']. Add it to esbuild config to remove all console.log/error/warn from shipped bundles.

low

No HTTP cache headers for static assets locally

Add express.static(..., { maxAge: '1y', immutable: true }) to server.js so local dev doesn't re-fetch bundles and assets every load.
