**Priority: Mobile layout needs fixing first before new features.**

## Feature Ideas (2026-03-20)

### Social / Multiplayer
- Shared rooms — real-time multi-user tape table (WebSocket/Supabase)
- Tape trading — shareable link/code to exchange tapes
- Public tape wall — browse and clone other people's tapes

### Discovery & Curation
- Mixtape — combine multiple videos into a custom ordered playlist
- Surprise me — surface /api/random more prominently, drop random tape on table
- Genre radio stations — pre-built infinite tapes, one-click add
- Related video suggestions after a tape finishes

### Visual & Vibe
- Custom tape labels — user text, color picks, small image uploads
- Tape aging — more worn look based on play count
- Ambient audio — tape hiss, mechanical click sounds on load/eject
- Visualizer — audio-reactive background/overlay
- Swappable table surfaces — felt, metal, bedroom floor, car dashboard

### Playback & UX
- Queue/playlist mode — line up multiple tapes to auto-play in order
- B-side — flip a tape for a second video/playlist
- Keyboard shortcuts — space, arrows, number keys
- Mini player mode — floating bar for background listening
- Sleep timer — auto-stop after N minutes/tracks

### Technical / Power User
- Import/export — JSON backup of tape collection
- Tape sorting — by recently played, most played, genre, date added
- Folders/shelves — labeled groups on the table
- Offline mode — cached tape metadata
- PWA support — installable home screen app
